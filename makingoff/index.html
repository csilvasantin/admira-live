El Mejor Consejo del Mundo

Convertir council-scumm.html en el primer consejo vivo, inteligente, generativo y operativo del ecosistema ADmiraNeXT.

1. Visión

El Mejor Consejo del Mundo no es una imagen estática ni un sistema de presentación de slides. Es un consejo vivo, inteligente y operativo que recibe briefs reales, debate internamente con agentes especializados, toma decisiones, genera actas y tareas automáticas, y se auto-actualiza en tiempo real en council-scumm.html.

Es el cerebro estratégico del ecosistema ADmiraNeXT.

2. Problemas actuales de council-scumm.html

  • Es una imagen estática (aunque bonita y retro)
  • Solo tiene dos modos pasivos: Leyendas / Coetáneos
  • El sistema de "Presentar" depende de una API externa que no está activa
  • No genera decisiones, actas ni tareas reales
  • No está conectado con Yarig ni con el flujo operativo

3. Arquitectura (7 capas)

CapaNombreFunción
1Input LayerRecibe briefs, datos de Yarig, métricas de admira.live, stock de Studio
2Memory LayerBase de conocimiento del ecosistema (decisiones anteriores, contexto, valores)
3Council Agents5-7 agentes especializados (CEO, CTO, CMO, CFO, Legal, Operaciones, Ética)
4Debate EngineSistema de debate multi-agente con rounds y scoring
5Decision LayerGenera resoluciones, votos, riesgos, próximos pasos
6Output LayerActa + tareas + notificaciones + actualización visual del council
7Feedback LoopAprende de qué decisiones se ejecutaron y cuáles no

4. Fases de implementación

Fase 0 — Fundación (1-2 semanas)

Conectar council-scumm.html con una API real (council-api.py o worker). Crear estructura de agentes base. Implementar memoria persistente (KV o base de datos).

Fase 1 — Primer Consejo Real (2-3 semanas)

Un briefing real entra → el consejo debate → genera acta + 3 decisiones. Actualización visual del council (nameplates cambian según rol activo). Integración con Yarig (recibe tareas reales).

Fase 2 — Consejo Operativo (3-4 semanas)

El consejo genera tareas en Yarig automáticamente. Sistema de votación y quórum. Historial de decisiones con trazabilidad.

Fase 3 — Consejo Estratégico (4-6 semanas)

Multi-consejo (Consejo de Administración + Consejo Operativo + Consejo Ético). Predicción de riesgos y oportunidades. Integración con XpaceOS y admira.live (el consejo ve el pulso en tiempo real).

6. Métricas de éxito

  • Tiempo entre briefing → decisión (objetivo: < 4 minutos)
  • % de decisiones que se ejecutan (objetivo: > 80%)
  • Reducción de meetings operativos (medir antes/después)
  • Satisfacción del equipo con las decisiones del consejo
